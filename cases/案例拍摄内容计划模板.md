# 一次拍摄，最大化产出
## 案例内容全周期计划模板

> 适用于：木属木艺工作室 | 小红书 + 抖音双平台
> 核心原则：**一次拍摄，素材分层，按节奏释放，持续发酵**

---

## 一、核心思路：把一个案例当成一部"连续剧"来运营

大多数人拍完案例，一次性发完就结束了。
正确的做法是：**把同一批素材，按不同目的拆解成不同内容，在4-6周内持续释放。**

每一条内容承担不同的任务：
- 有的负责**跑流量**（吸引陌生人）
- 有的负责**建信任**（让人想关注你）
- 有的负责**促转化**（让有需求的人来咨询）
- 有的负责**留粉丝**（让已关注的人持续互动）

---

## 二、拍摄前：素材规划清单（拍摄当天必须完成）

### 2.1 必拍素材（不拍就没有）

**A 类：探家长视频素材（连续走动，完整记录）**
- [ ] 全屋漫步（从入户门到每个房间，不剪辑，连续拍）
- [ ] 每个空间的全景（站在门口，固定机位，5秒以上）
- [ ] 每个空间的核心亮点特写（慢推镜头，3-5秒）

**B 类：切片短视频素材（独立亮点，单独拍摄）**
- [ ] 每个"反常规"细节的揭晓镜头（关门→开门、关灯→开灯等）
- [ ] 每个材质/工艺的触摸特写（手摸台面、推拉柜门、开合五金）
- [ ] 每个空间的"使用状态"（打开抽屉、坐在椅子上、站在窗边）

**C 类：图文素材（静态，高颜值）**
- [ ] 每个空间的"杂志感"构图（三分法、对称、留白）
- [ ] 细节特写（材质纹理、五金件、灯光氛围）
- [ ] Before & After 对比（如有施工前照片）

**D 类：人物素材（博主出镜）**
- [ ] 博主在不同空间的"发现"反应（走进去、摸一下、回头说话）
- [ ] 博主指向细节的手势特写
- [ ] 业主惊鸿一瞥（如业主愿意）：在自己家里自然状态的1-2个镜头

### 2.2 拍摄时要问业主的3个问题（用于脚本素材）
1. **这个家里，你最喜欢哪个角落？为什么？**
2. **有没有哪个细节，是你坚持要做的，别人觉得没必要？**
3. **住进来之后，有没有哪个地方让你觉得"这个真的用对了"？**

> 这3个问题的答案，是后续所有内容的"情感内核"。

## 三、内容产出清单：一个案例可以产出多少条内容？

| 内容类型 | 数量 | 平台 | 核心目的 |
| :--- | :--- | :--- | :--- |
| 探家长视频（3-8分钟） | 1条 | 小红书 | 建立专业信任，获取精准关注 |
| 切片短视频（30秒-1.5分钟） | 5-8条 | 小红书 + 抖音 | 跑流量，触达陌生用户 |
| 图文笔记（9宫格） | 2-3组 | 小红书 | 搜索流量，沉淀收藏 |
| 单图/氛围图 | 3-5张 | 小红书 | 颜值种草，引发收藏 |

**合计：一次拍摄 = 11-17条内容，可支撑4-6周的持续发布。**

## 四、切片短视频的7种类型（每种目的不同）

这是整个计划的核心。同一批素材，按不同角度切，服务不同目的。

### 类型①：颜值冲击型（跑发现页泛流量）
**目的**：让从未见过你的人停下来，产生"哇"的感受。
**内容逻辑**：最高颜值的画面 + 反预期开场 + 快节奏剪辑
**示例**：`这居然是干区？` / `这面墙后面藏了什么`
**时长**：20-40秒
**发布平台**：小红书 + 抖音同步

### 类型②：细节拆解型（跑搜索精准流量）
**目的**：让正在搜索"某某设计怎么做"的用户找到你。
**内容逻辑**：一个具体设计细节 + 讲清楚为什么这样做 + 讲清楚好在哪里
**示例**：`内嵌窗口是怎么做的` / `四分离卫浴的逻辑`
**时长**：40秒-1.5分钟
**发布平台**：小红书为主（搜索场景更强）

### 类型③：避坑/解决问题型（跑搜索 + 评论互动）
**目的**：让有具体困惑的用户找到你，并在评论区讨论。
**内容逻辑**：一个真实遇到的问题 + 解决过程 + 结果
**示例**：`洗烘机共振噪音怎么解决` / `小户型收纳怎么做`
**时长**：40秒-1.5分钟
**发布平台**：小红书 + 抖音

### 类型④：情绪/生活方式型（跑收藏 + 关注）
**目的**：让用户产生"我也想要这样的家"的情感共鸣，收藏 + 关注。
**内容逻辑**：业主的真实想法 + 三层认同链结构 + 开放式互动问题
**示例**：`她不要冷冷的家` / `她按自己的样子装了这个家`
**时长**：40秒-1.5分钟
**发布平台**：小红书为主

### 类型⑤：反转/对比型（跑点赞 + 分享）
**目的**：制造强烈的情绪冲击，触发点赞和分享。
**内容逻辑**：Before & After / 预期 vs 现实 / 以为是这样其实是那样
**示例**：`以为要换机器，结果一块海绵垫解决了` / `这不是样板间，是真实住着人的家`
**时长**：20-40秒
**发布平台**：小红书 + 抖音同步

### 类型⑥：工艺/专业展示型（跑B端客户 + 建立专业壁垒）
**目的**：让同行和潜在B端客户（设计师、装修公司）看到你的工艺水准。
**内容逻辑**：一个具体工艺细节 + 为什么这样做 + 效果对比
**示例**：`不锈钢台盆的焊接工艺` / `吊轨移门的安装细节`
**时长**：40秒-1分钟
**发布平台**：小红书为主

### 类型⑦：系列/连载型（跑关注 + 留存）
**目的**：让用户因为期待下一集而关注你。
**内容逻辑**：把一个完整案例拆成3-5集，每集聚焦一个空间或一个主题，结尾预告下一集
**示例**：`政立路53平 | 第一集：入户和走廊` / `第二集：卫生间四分离`
**时长**：1-2分钟
**发布平台**：小红书为主

## 五、发布节奏：6周内容日历

### 第1周：引爆期（用最强内容开场）

| 天 | 内容 | 类型 | 平台 | 目的 |
| :--- | :--- | :--- | :--- | :--- |
| 第1天（周五晚8点） | 颜值最强的切片短视频 | 颜值冲击型 | 小红书 + 抖音 | 第一波曝光 |
| 第3天（周日晚8点） | 情绪最强的切片短视频 | 情绪/生活方式型 | 小红书 | 收藏 + 关注 |

> **第1周策略**：只发2条，不要一次性全发完。用最强的2条先测试账号的基础流量池，观察哪个方向数据更好，为后续内容调整方向。

---

### 第2周：深耕期（扩大覆盖面）

| 天 | 内容 | 类型 | 平台 |
| :--- | :--- | :--- | :--- |
| 周一晚8点 | 细节拆解短视频（如：内嵌窗口） | 细节拆解型 | 小红书 |
| 周三晚8点 | 避坑/解决问题短视频（如：洗烘机共振） | 避坑型 | 小红书 + 抖音 |
| 周六晚8点 | 高颜值图文（9宫格，全屋概览） | 图文 | 小红书 |

---

### 第3周：信任建立期（发探家长视频）

| 天 | 内容 | 类型 | 平台 |
| :--- | :--- | :--- | :--- |
| 周三晚8点 | 探家长视频（3-8分钟，完整案例） | 探家长视频 | 小红书 |
| 周六晚8点 | 反转/对比短视频 | 反转型 | 小红书 + 抖音 |

> **第3周策略**：探家长视频是信任建立的核心武器，但不要第一周就发。先用短视频积累一批对这个案例感兴趣的用户，再发长视频，完播率和收藏率会更高。

---

### 第4周：专业背书期

| 天 | 内容 | 类型 | 平台 |
| :--- | :--- | :--- | :--- |
| 周二晚8点 | 工艺/专业展示短视频 | 工艺展示型 | 小红书 |
| 周五晚8点 | 图文（细节特写，材质纹理） | 图文 | 小红书 |

---

### 第5-6周：长尾发酵期

| 天 | 内容 | 类型 | 平台 |
| :--- | :--- | :--- | :--- |
| 每周1-2条 | 系列/连载短视频（按空间拆解） | 系列型 | 小红书 |
| 适时补发 | 根据前4周数据，复刻表现最好的类型 | 复刻爆款 | 小红书 + 抖音 |

## 六、数据复盘节点与迭代动作

### 发布后48小时：快速诊断

每条内容发布后48小时，记录以下数据：

| 指标 | 健康值 | 如果低于健康值 |
| :--- | :--- | :--- |
| 点击率（曝光→播放） | >10% | 封面/标题需要优化 |
| 完播率 | >40% | 开场前3秒需要更强的钩子 |
| 收藏率（收藏/播放） | >3% | 内容缺乏实用价值或情感共鸣 |
| 评论率（评论/播放） | >0.5% | 结尾互动钩子需要更具体 |

### 第1周结束：方向确认

根据第1周2条视频的数据，判断：
- 哪种类型（颜值冲击 vs 情绪共鸣）在你的账号上更有效？
- 后续内容向表现更好的方向倾斜。

### 第3周结束：全面复盘

- 哪条视频的收藏率最高？→ 这是你的"内容资产"，可以做成系列。
- 哪条视频的评论最多？→ 评论里的问题，就是下一个案例的选题。
- 哪条视频带来了私信咨询？→ 这是你的"转化型内容"，要持续复刻。

---

## 七、一句话总结

> **不要把一个案例当成一次发布，要把它当成一季内容来运营。**
> 拍摄当天是"原材料采购"，后续6周是"持续加工和分发"。
> 每一条内容都有它的任务，每一个数据都是下一次迭代的指令。
