# 政立路 统一拍摄清单
## 一次拍摄，覆盖全部内容所需镜头

> 按空间顺序走，每个空间拍完再移动。
> 标注【关键】的镜头是脚本核心，不能缺；其余是补充素材。

---

## 开拍前确认

- [ ] 洗烘机两侧缝隙的海绵垫备好（短4需要实拍塞入过程）
- [ ] 八百库门推开状态：杂物正常摆放，不要刻意整理
- [ ] 卫生间台面：擦干净，无水渍
- [ ] 自然光确认：阳台书桌、卧室窗台需要自然光效果
- [ ] 猫在不在（长视频沙发镜头加分）

---

## 一、玄关 / 八百库区

### 【关键】八百库——门关状态
- [ ] 走廊全景：门关着，镜子完整，走廊干净整洁（固定机位，5秒以上）
- [ ] 镜子特写：移门中间嵌镜的细节
- [ ] **抖音封面备选**：正对走廊拍，左右构图留空，后期可做对比图

### 【关键】八百库——门推开状态
- [ ] 门推开全景：杂物全部可见（雨伞/登山杖/瑜伽垫/快递）
- [ ] 杂物细节特写：几样典型物件的近景
- [ ] 门推开→门关上的连续动作（一镜到底，不剪）

### 注意
- 镜子拍摄：镜头不要正对，避免摄影师和设备入镜
- 门开+门关两个状态都要拍完整，短1两个平台都要用

---

## 二、厨房

- [ ] U型布局全景（站在入口，固定机位）
- [ ] 灶台+烤箱一体的特写（正面+侧面）
- [ ] 灶台与柜子衔接处的细节（短1拍摄时顺带）

---

## 三、餐厅

### 【关键】内嵌窗口
- [ ] 从餐厅角度：镜头对准那堵墙，方形开口居中，透过去能看到卧室灯光（固定机位）
- [ ] 镜头慢推向开口：从餐厅位置推进，接近开口（给抖音第一帧用）
- [ ] 透过开口看卧室内部的视角（模拟站在餐厅的主观视角）
- [ ] 开口的边缘细节（墙体厚度、收口工艺）

### 餐边柜 / 洗烘机区
- [ ] 餐边柜+洗烘机叠放一体的全景（门关着，像完整收纳柜）
- [ ] 柜门打开：洗烘机露出的状态

### 搁板
- [ ] 搁板全景（唱片/海报/照片，完整一排）
- [ ] 搁板细节特写（1-2件有特点的物件）

---

## 四、卫浴

### 【关键】台面
- [ ] 台面全景（正面，含门板配色）
- [ ] **手摸台面特写**：手从左往右轻摸，动作自然，暖色木纹质感清晰可见（短5封面 + 抖音第一帧）
- [ ] 台面与门板拼色效果（斜侧角度）

### 镜柜
- [ ] 镜柜+两侧开放格整体（正面）
- [ ] 开放格细节（置物情况）

### 注意
- 台面拍摄：避免水渍反光
- 手摸动作要拍够长（5秒以上），后期可截取

---

## 五、卧室

### 【关键】双开门
- [ ] 双开门外观（从走廊/餐厅角度，门关着）
- [ ] 推开双开门的完整动作（一镜，慢推）
- [ ] 艺术玻璃细节特写（金属夹丝纹路）

### 卧室内部
- [ ] 进门全景（护墙板+窗台板整体）
- [ ] 窗台板细节（自然光效果）
- [ ] 护墙板质感特写

### 【关键】猫洞
- [ ] 墙角猫洞正面（能看出是特意做的小开口）
- [ ] 猫洞尺寸感（手比对）

---

## 六、客厅

- [ ] 沙发+投影区全景
- [ ] 如猫在场：猫在沙发上的自然状态（不摆拍）

---

## 七、阳台

- [ ] 阳台书桌全景（整个阳台即桌面的大景，自然光）
- [ ] 坐在书桌前的主观视角（窗边光线）
- [ ] 桌面细节（书/物件）

---

## 八、全屋漫步（长视频专用）

> 最后拍，拍摄者要走一遍全程再拍，路线熟悉后一镜连续完成。

- [ ] 从入户门开始，连续走过：玄关→厨房→餐厅→卫浴→卧室→客厅→阳台
- [ ] 节奏：每个空间停留1-2秒，不停下来讲解，纯走动
- [ ] 至少拍2-3遍，备选
