# 政立路案例｜最终拍摄执行包
基于《最终脚本完整版本》重整｜参考 yangbenku 拍摄清单样式

---

> **角色定位（全程遵守）**
> 木属木艺的角色 = 木作落地者 / 案例呈现者，不宣称整案原创设计。
> 所有口播和字幕不说"我们设计了……"，说"我们做了……""我们落地了……"。
> 内嵌窗口只说"特意开了一个口"，不说"拆墙改造"，避免评论区追问施工资质。

## 一、开拍前准备

### 装备清单

| 设备 | 必须/可选 | 备注 |
|---|---|---|
| iPhone（建议 Pro 系列）| 必须 | 主拍设备，确认存储空间 > 50GB |
| 三脚架 | 必须 | 所有固定机位镜头都要用，不能全手持 |
| 手机稳定器（云台） | 强烈建议 | 全屋漫步、推镜必须用，否则画面晃 |
| 补光灯（小型便携）| 建议 | 内嵌窗口卧室侧补光、卫浴台面特写用 |
| 备用充电宝 | 建议 | 拍摄时间长，手机容易没电 |
| 海绵垫（2-4块）| 必须带去 | 短4洗烘机现场实拍，不能只靠业主备 |

### 拍摄前各空间场地准备

**八百库 / 玄关**
- [ ] 八百库内杂物：正常摆放，不要刻意整理，保留真实感，但不能脏乱（有层次）
- [ ] 走廊地面：扫干净，无多余杂物
- [ ] 移门关闭状态：镜子干净，无水渍指纹
- [ ] 八百库内灯打开；关掉走廊过强光源，避免镜面强反光

**厨房**
- [ ] 灶台台面擦干净；无多余餐具
- [ ] 灶台、烤箱接缝处擦净

**餐厅 / 内嵌窗口**
- [ ] 卧室灯打开（透过开口要有层次，不能一片黑）
- [ ] 餐桌上无多余杂物
- [ ] 搁板：唱片/海报/照片保持原状，不要动

**洗烘机**
- [ ] 海绵垫备好，放在洗烘机旁边（等待实拍塞入过程）
- [ ] 柜门可以开合顺畅

**卫浴**
- [ ] 台面擦干净，无水渍
- [ ] 洗漱用品整理或移出镜头外
- [ ] 镜柜开放格：适当整理，不要乱

**卧室**
- [ ] 双开门可顺畅推开
- [ ] 护墙板、窗台板无明显灰尘
- [ ] 猫洞周围干净

**阳台**
- [ ] 书桌面清空或只留1-2件物品
- [ ] 确认自然光时间（建议上午 9:00-11:00 拍，侧光最好）
