# 案例仓库

这个目录用于单独沉淀每个案例的原始资料、木作信息、图片资料和后续内容生产所需的基础说明。

## 使用方式

1. 每来一个新案例，复制 `新案例模板` 文件夹。
2. 把复制后的文件夹改成案例名称，例如：`政立路`、`法华镇路`。
3. 按顺序填写：
   - `01_基本信息.md`
   - `02_木作内容.md`
   - `03_图片资料.md`
   - `04_故事点与补拍.md`
4. 图片放到对应的图片文件夹里：
   - `图片/平面图`
   - `图片/现场实景图`
   - `图片/细节图`

## 目录结构

```text
案例仓库/
  README.md
  新案例模板/
    01_基本信息.md
    02_木作内容.md
    03_图片资料.md
    04_故事点与补拍.md
    图片/
      平面图/
      现场实景图/
      细节图/
```

## 填写原则

- 先真实，后精修。
- 信息越具体，后面越容易生成脚本、拍摄清单、发布文案和复盘表。
- 特殊工艺、非常规做法、真实问题解决、业主原话，是内容价值最高的部分。
- 图片不需要精修，手机随手拍也可以，关键是覆盖全景、动线和细节。
