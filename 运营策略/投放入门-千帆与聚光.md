# 投放入门：千帆与聚光

## 投放的基本逻辑

```
先发自然流量内容
→ 找到数据最好的那一条（点赞/收藏/评论最高）
→ 把钱押在它上面放大
```

不是随便烧钱，是给**已经证明有效的内容**加速。

---

## 小红书 → 聚光平台

### 入门路径

**第一步：薯条**（最简单的推广工具）
- 选一篇点赞收藏还不错的笔记
- 花 100-200 元，看数据变化
- 目的：感受"付费流量长什么样"

**第二步：聚光平台**
- 数据有感觉之后，上聚光做精细化投放
- 可以设定人群、地域、兴趣标签

### 适合推的内容类型
- 有明显 before/after 对比的
- 评论区有人问"在哪做的/怎么联系"的
- 收藏数明显高于点赞数的（说明实用价值高）

---

## 抖音 → 千帆

千帆主要是**数据分析工具**，不是直接投放的入口。

### 用来做什么
- 分析竞品账号的数据表现
- 看哪类内容在家装领域转化率高
- 找到内容方向的依据，再决定怎么拍

### 使用顺序
先用千帆**研究和分析**，再决定投什么、怎么投。
