# 短视频发布前 QC 清单
## 小红书版 / 抖音版（分平台）

> 原五层（钩子/留存/互动/价值感/画面质量）升级版。
> 核心改动：①平台拆分 ②抖音加入完播率维度 ③画面质量细化为具体问题

---

## 小红书版（6层）

### 第1层：钩子（封面层）
封面标题能不能让人想点进来？

- [ ] 是悬念型、颜值冲击型、痛点型中的一种
- [ ] 标题不超过20字，核心词靠前
- [ ] 封面画面本身够不够有视觉吸引力

### 第2层：节奏（中段留存）
中间段有没有让人半途而废的理由？

- [ ] 有没有信息密度明显跌落的段落
- [ ] 没有重复表达同一个意思的地方
- [ ] 每隔10-15秒有新的信息点或画面切换

### 第3层：留存（收藏理由）
有没有明确的收藏理由？

- [ ] 有可以复用的方法或原理（干货/清单/决策依据）
- [ ] 结尾有明确的收藏引导语

### 第4层：互动（评论引导）
结尾问题能不能让人想回答？

- [ ] 问题具体，不宽泛（"你家有没有做过这个？"而不是"你觉得家装重要吗？"）
- [ ] 内省型/分享型均可（小红书两种都有效）

### 第5层：价值感
看完有没有获得感？

- [ ] 用户能带走一个观点、一个方法或一个决策角度
- [ ] 不是纯颜值展示，有实质内容

### 第6层：画面质量（具体检查）

- [ ] 是否有"揭晓"镜头（门开/门关、改造前后等反差画面）
- [ ] 是否有细节近景（手摸材质、五金、关键工艺）
- [ ] 镜子/玻璃拍摄是否检查了反光（摄影师和设备不入镜）

## 抖音版（6层）

### 第1层：钩子（前3秒）
第一帧画面 + 第一句台词，零铺垫，直接命中？

- [ ] 第一帧是对比图 / 揭晓画面 / 高颜值冲击，不是过渡镜头
- [ ] 第一句台词和画面同步命中痛点，不铺垫
- [ ] 前3秒结束时，用户已经知道这条视频在说什么

### 第2层：完播率（中段）
⚠️ 抖音核心指标。算法最看重这个，不是钩子。

- [ ] 中间段有没有让人想划走的"死区"（信息断层/重复表达）
- [ ] 视频长度是否匹配内容密度（能30秒说完的不拖到60秒）
- [ ] 有没有"悬念预告"勾住中段（"第2个是最多人忽略的"）

### 第3层：留存
有没有收藏/复用价值？

- [ ] 有可以记住并用上的具体方法或原理
- [ ] 不是只有颜值，有实质内容

### 第4层：互动（评论触发）
结尾问题是否争议型 / 表态型 / 转发型？

- [ ] ✅ 争议型：两派都有话说（"实用还是智商税？"）
- [ ] ✅ 表态型：用户要站队（"你会不会这样做？"）
- [ ] ✅ 转发型：用户有动机发给别人（"身边有装修的转给他"）
- [ ] ❌ 禁止内省型：不用"你家有没有这样的地方？"（不触发分享）

### 第5层：分享触发
有没有"发给正在装修的朋友"的理由？

> 分享是抖音权重最高的互动行为，比点赞/收藏更影响推流。

- [ ] 内容是否有"装修前必看"的实用价值
- [ ] 是否有一个让人想立刻转发的"反常识"或"救命信息"点

### 第6层：画面质量（具体检查）

- [ ] 第一帧是否足够强——如果截图发出去，能不能让人想点进来
- [ ] 是否有对比/揭晓镜头（两个状态都拍了）
- [ ] 是否有细节近景（手摸/五金/工艺）
- [ ] 镜子/玻璃拍摄是否检查了反光

---

## 两版的核心差异一句话总结

| | 小红书 | 抖音 |
|---|---|---|
| 钩子位置 | 封面标题 | 第一帧+第一秒台词 |
| 最重要指标 | 收藏率 | 完播率 |
| 互动目标 | 收藏/评论 | 分享 > 评论 |
| 结尾问题类型 | 内省型/分享型均可 | 只用争议型/表态型/转发型 |
