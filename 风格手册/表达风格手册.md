从用户在2026-05-20亲自写的"政立路卫浴台面"那段台词里提取。
她写完后说："这就是了"——这是她真实的表达风格，不是设计的，不是模仿的。

**所有未来的内容生成必须按这个风格走。**

## 一、核心人设

```
"一个有审美、懂行、爱分享的朋友姐姐"

✓ 不是设计师
✓ 不是博主
✓ 不是表演者

✓ 是"我"，但说"我们"（工作室视角）
✓ 是"分享者"，不是"推销者"
✓ 是"懂行的朋友"，不是"专家"
```

---

## 二、用词习惯（必须遵守）

### 称呼习惯
- ✅ "你们"，不是"你"（亲切感、群体感）
- ✅ "朋友们" 作为称呼（自然的口语）
- ✅ "评论区的朋友们" 作为互动引导
- ❌ "宝子们"（太网感）
- ❌ "家人们"（太电商）
- ❌ "兄弟姐妹们"（不自然）

### 视角代词
- ✅ "我们" 指工作室团队（不是"我"）
- ✅ "他/她" 指业主（口语习惯，不严格区分性别）
- ✅ "业主" 这个词可以直接用

### 强调用词
- ✅ "整整" + 数字 + "啊朋友们"
  例："整整2米2啊朋友们"
- ✅ "都" 表强调
  例："我们都惊呆了"
- ❌ "天啊"、"绝了"、"OMG"（太夸张）
- ❌ "无敌"、"绝绝子"、"yyds"（太网感）

## 三、句式特征（可复用模板）

### 1. 开头钩子：悬念猜谜式
```
"你们猜 + [具体物品] + 是 + [什么] + 做的？"
"你们知道这个 + [东西] + 为什么 + [反常的现象] + 吗？"
```

### 2. 排除式悬念
```
"[选项A]？[选项B]？[选项C]？
都不是。"
```
→ 制造悬念，强化下一句的揭晓

### 3. 业主原话引用
```
"他/她跟我们说——
[业主的需求/想法]"
```
→ 让叙述有真实感和温度

### 4. 转折型引入走心段
```
"但是你知道吗？"
"虽然这个不是正常的做法，但是..."
```
→ 从故事性转入情感性的过渡

### 5. 金句结构：对仗反转
```
"他/她/这个家 不是 [常规做法]，
他/她/这个家 是 [自己想要的样子]"
```
→ 这是你写得最好的金句结构，可以多次复用：
- "她不是按规矩装家，她是按自己的样子装家"
- "这个家不是设计出来的，是住出来的"
- "我们不是在做柜子，我们是在做一个'她想要的家'"

### 6. 互动引导：具体+开放
```
"评论区的朋友们可以告诉我，
你们家有没有 + [具体的场景/细节]，
是 + [情感动作 - 坚持/喜欢/纠结/犹豫] + [具体的事]？"
```
→ 不要问宽泛的"欢迎评论"
→ 要问"让对方立刻想到自己"的具体问题

## 四、情绪节奏曲线

用户的真实情绪曲线（基于真实台词）：

```
钩子（悬念）→ 揭晓（小高潮）→ 故事讲述（平稳）→
事实强调（小情绪）→ 转折（柔下来）→ 业主原话（温柔）→
金句升华（稳重）→ 邀请互动（温柔）
```

**特征**：
- **不是急促爆发** → 是**绵长讲故事**
- **有起伏但克制** → **不夸张**
- **重点处有停顿** → 让观众消化
- **结尾真挚** → 不套路

## 五、诚信定位的自然流露（重要）

不要刻意说"我们不是设计师"，而是通过**词语选择**自然流露：

### 推荐用词
- ✅ "我们做了..."（落地者视角）
- ✅ "我们按照她的想法去落地的"（强调"落地"）
- ✅ "我们跟业主说..."（合作者视角）
- ✅ "送到工厂去做..."（暗示供应链能力）
- ✅ "我们都惊呆了"（团队视角，不是设计师权威）

### 不要的词
- ❌ "我设计的..."（误导）
- ❌ "我们的设计..."（误导）
- ❌ "我们是设计师"（直接的错位）

### 文案备注（在视频描述里）
```
———————
关于这个案例：
设计师 @XXX
我们做了硬装中的木作部分
是这个家的呈现者，分享给你们
———————
```

## 六、内容结构模板（短视频）

```
1. 钩子（5-10秒）       → 提一个具体问题/悬念
2. 揭晓（3-5秒）        → 给一个意外答案
3. 故事（15-25秒）      → 业主背后的故事/经过
4. 强调/事实（3-5秒）   → 重申一个关键点
5. 转折（3-5秒）        → "但是你知道吗？"
6. 业主的真实想法（10-15秒） → 引用原话/讲心声
7. 金句升华（5-8秒）    → "不是X，是Y" 结构
8. 互动邀请（5-10秒）   → 具体+开放的问题
```

## 七、严禁踩雷（永远不要做）

```
❌ 不要刻意夸张（"天啊！绝了！瞪眼！")
❌ 不要演（语气太设计、表情太刻意）
❌ 不要用网络流行词（"绝绝子、yyds、宝子")
❌ 不要太多镜头/情绪标注（干扰自然表达）
❌ 不要"专家"口气（"我告诉大家..."）
❌ 不要把所有句子切碎（双人对话已舍弃）
❌ 不要替业主"代言"过头（保持你的视角）
❌ 不要在视频里反复强调身份（用文案备注就好）
```

## ⭐⭐ 八点五：视角转换 + 认同链（2026-05-20 最新发现）

### 你不"代入业主"，你"欣赏业主"

**错误的设计**：
"我不是一个爱打理的人..."（让你扮演业主的视角）

**正确的设计**：
"她跟我说她不爱打理...我觉得她这个观点很明智...因为我也觉得..."
（你保持"分享者"视角，识别+认同+延伸业主的好观点）

### 三层认同链结构（关键模板）

```
① 业主："我..." （真实想法/需求）
   ↓
② 你（分享者）："我觉得她这个观点很明智，因为我也觉得..."  
   ↓ （审美判断 + 个人认同）
③ 我们（观众+你）："通过XX，可以让我们..." （普适价值）
```

### 这个结构为什么强

1. **业主继续是业主** —— 不被你"代言"
2. **你保持"懂行的朋友"定位** —— 你的工作是"识别什么是好的"
3. **观众被拉进共识** —— "让我们..."创造了共同体感

### 句式模板（可复用）

```
她跟我说，[业主的真实想法/需求]
我觉得她这个观点是特别明智的。
因为我也觉得，[你认同的普适观点]
[把这个观点延伸到"我们"/观众的生活]
```

### 应用举例

```
（卫浴台面案例）
她跟我说，她不要冷冷的家
→ 我觉得她按自己想要的样子装家这件事，是值得我们学习的
→ 因为家本来就该是按自己的样子来

（八百库案例）
她跟我说，她不爱打理但希望设计帮她解决
→ 我觉得她这个观点是明智的
→ 因为我也觉得，设计应该为生活服务
```

## 九、关于"金句"的纠正（2026-05-20）

**之前的错误理解**：把"设计应该为生活服务的"这种观点表达，硬包装成"金句段"

**正确的理解**：
- 你的态度表达 ≠ 金句
- 不需要刻意做"金句"
- 真诚的观点，朴素的语言，自然停下，就是最好的
- 如果有对仗结构出现（如"不是X，是Y"），让它**自然出现**，不要为了金句而金句

### 严禁

```
❌ 强行加"金句段"
❌ 把朴素的观点诗化包装
❌ 在每一条结尾刻意做总结
```

### 推荐

```
✅ 让观点就是观点，自然真诚地说
✅ 让结尾自然停下，不强加互动
✅ 互动引导只在"有具体话题"时加（如"按自己样子装家"的那条），不是每条都要

## 九、参照案例（金句和经典段落）

```
"她不是按常规概念去装扮家，
她是按照自己想要的样子，
装了一个属于自己的家"

"那个只属于你们自己的家的样子"

"生活也好，空间也好，都是需要缓冲的。
这道门的背后，就是这个缓冲的作用——
让你不管面对什么情况，
都能轻松自在，游刃有余。"
```

### 用户的"升华词汇"（从功能到哲学）

用户有能力把具体的功能/设计，升华成一个生活哲学：
- **"缓冲"**：收纳的意义不只是藏东西，是给生活留缓冲空间
- **"按自己的样子装家"**：不是设计审美，是生活自主权
- **"设计为生活提供服务"**：设计的本质

这些词/观点是她真正的洞察，比任何"金句"都有力。
**每次内容创作时，引导这类升华自然出现，而不是强行设计。**

## 应用方式

**所有未来的脚本生成、文案撰写、台词设计**：
1. 第一步：先在心里问"如果用户她本人来说，会怎么说？"
2. 第二步：按本手册的句式和节奏写
3. 第三步：写完后比对本手册的"严禁踩雷"清单
4. 第四步：朗读一遍，看是不是"她的味道"
