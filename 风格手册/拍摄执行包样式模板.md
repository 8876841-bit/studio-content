# 拍摄执行包样式模板

> 本模板用于沉淀以后所有案例拍摄执行包的统一样式。
> 完整样本同步存放于 `yangbenku/模板/拍摄执行包样式模板.md`，本文件作为 `studio-content/风格手册` 内的标准规范版本。

---

## 1. 使用规则

1. 先确认最终脚本，再拆拍摄执行包。
2. 执行包必须回答三个问题：现场拍什么、怎么拍、离场前检查什么。
3. 每个案例建议保留两类文件：
   - 最终脚本完整版本：台词、平台版本、QC 检查。
   - 拍摄执行包：分镜、动作、视频补镜、照片补镜、现场顺序。
4. GitHub 内保留 Markdown 版本，便于预览、复制和版本管理；对外协作可另存 Word 版本。

## 8. 现场拍摄顺序

1. 进场前：确认光线、收拾杂物、清洁镜面、确认业主是否可轻出镜。
2. 先拍全屋动线：玄关 → 厨房 → 餐厅 → 卫浴 → 卧室 → 阳台。
3. 再拍短视频核心动作：门开关、台面手摸、海绵垫塞入、窗口推近等。
4. 再拍无人补镜：空间全景、材质细节、氛围空镜。
5. 最后拍照片：封面图、全景图、细节图、对比图。
6. 离场前现场回看，不要回家才发现漏拍。

## 11. 不可破坏的原则

1. 不夸大设计归属。
2. 不为了流量牺牲事实准确性。
3. 不只拍好看的画面，必须拍能剪成内容的画面。
4. 每个空间至少要有：全景、动作、细节、氛围、照片五类素材。
5. 执行包不是写给自己看的，是写给现场执行的人看的。
